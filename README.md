# HawkView (호크뷰)

폴더와 압축 파일을 빠르게 넘겨 보는 이미지 뷰어. 맥에서도 윈도우에서도 같은 화면으로 움직입니다.

An image viewer for folders and archives that is fast to flip through, and looks and works the same on Mac and Windows.

> 이 저장소는 HawkView의 **배포용**입니다. 앱의 소스는 공개하지 않고, 설치 파일과 업데이트 목록만 올립니다. · This repository only hosts HawkView's installers and update feeds; the source code is not published.

## 무엇을 하나

- 폴더를 열면 썸네일 격자로 훑고, 그림을 열면 창을 다 쓰는 화면으로 넘겨 봅니다.
- ZIP·RAR·7z·tar 압축 파일 안의 그림을 풀지 않고 바로 봅니다. 두 장 보기·웹툰 넘김·넓은 쪽 나누기를 지원합니다.
- JPEG·PNG·WebP·GIF·TIFF 같은 흔한 형식과 HEIC·AVIF·JPEG XL(OS 코덱 사용)을 엽니다.
- 막대·메뉴·설정을 직접 그려서 맥과 윈도우가 같게 보이고 같게 동작합니다.
- 광고·추적·회원 가입이 없습니다. 열어 본 그림은 기기 밖으로 나가지 않습니다(자세한 것은 [개인정보처리방침](PRIVACY.md)).

## 내려받기

- **맥 (macOS)**: [Releases](https://github.com/eddykim/hawkview/releases)의 최신 `.dmg`. Apple의 Developer ID로 서명·공증했습니다.
- **윈도우**: Microsoft Store 판을 준비 중입니다.
- 지금은 베타 전 단계라 정식 릴리스가 없습니다.

## 베타 테스트

베타를 받아 보실 분은 support@hawkviewer.app으로 "HawkView 베타"라고 보내 주세요(맥을 쓰시는 분 우선). 베타 판은 프리릴리스로 올라가며, 베타끼리는 자동으로 업데이트됩니다. 문제가 생기면 앱 정보 창(F1)의 **진단 정보 복사**를 눌러 메일이나 이슈에 붙여 주세요. 판·OS·GPU·설정 요약만 담기고 개인 경로는 들어가지 않으며, 앱이 이 글을 스스로 보내지는 않습니다.
